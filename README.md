### 重要警告

1. **5人打車 = 需要 2 台車 或 1 台7座商務車**（普通計程車/滴滴最多載4人）
   - Day 2-3 建議包全日 7 座車（¥700/天，可殺兩天價）
2. **凌晨 05:30 叫車風險高**（滴滴 06:00 前車少）→ 前一晚用滴滴「預約用車」功能鎖定，或跟包車師傅約好
3. **若有人持外國護照**：下單前先問房東能否接待外賓（部分民宿無涉外資質）

## 六、紅色警戒事項

1. 水簾洞 8/25-26 已約滿 -> 放棄，改玩大瀑布觀景台+犀牛潭
2. 天星橋索道停運至2027 -> 走干河溝替代路線，預留3小時
3. 龍宮/織金洞當日不售票 -> 必須提前1天以上預約
4. G4576 非每日開行 -> 立即搶票，備案 G2923
5. 8月多雨（60-70%機率）-> 備好雨具與 Plan B
6. 5人打車 = 2台車或7座 -> 每次移動都要安排
7. 凌晨05:30叫車風險高 -> 前一晚預約用車
8. 外國護照住宿 -> 下單前問房東能否接待外賓
9. 烏蒙大草原車程長（單程2.5h）+ 海拔2857m -> 前一晚確認包車、帶外套、查天氣

## 九、外地旅客行前清單（香港/海外）

1. **行動支付**：安裝支付寶國際版（綁定Visa/Mastercard）+ 微信支付，行前測一筆小額交易，備 ¥1000 現金
2. **景點實名預約**：持回鄉證/護照透過攜程/美團購買。水簾洞/龍宮需「安旅通」+ 大陸手機號（可請房東代註冊）
3. **網路**：安裝高德地圖/百度地圖，行前買 eSIM/漫遊
4. **高鐵取票**：12306 或 Trip.com；持護照需人工窗口取票
5. **保險**：旅遊保險（含登山/瀑布/高鐵延誤）
6. **充電**：2顆20000mAh行動電源 + 萬用轉接頭
7. **雨具**：雨衣、防滑鞋、快乾衣物、手機防水袋
8. **保暖**：龍宮/織金洞恆溫10-16度、烏蒙大草原海拔2857m，帶薄外套/防風外套
9. **藥品**：腸胃藥（辣食）、暈車藥、創可貼、防蚊液
10. **包車**：Day 2-3 建議包全日7座車（¥700/天），可請民宿房東代訂
